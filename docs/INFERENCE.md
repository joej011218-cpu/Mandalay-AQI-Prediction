# Verified inference contract

All 24 artifacts declare `XGBoost_DeltaOnly`, Indian CPCB AQI, `cpcb-2014-rolling-v1`, horizons 1–24, 198 features, and Asia/Yangon timestamps. Every booster's feature names, order and count match its own feature list and the common training manifest. Each uses `reg:squarederror`. SHA-256 hashes and the complete ordered list are recorded in `model_validation.json`.

`training/Mandalay_CPCB_XGBoost_Delta24_Colab.ipynb`, supplied locally, contains feature functions whose AST exactly matches the original Downloads `train_mandalay_cpcb_delta24.py`. `prediction/training_features.py` copies **only** its constants, `calculate_targets`, and `build_features`; the CPCB import is relative. No fit or training entry point is included in application code. The notebook is reference material and is not executed by deployment.

1. Read the existing database's canonical Yangon hourly grid, ignoring future rows. Include the latest observation and 191 earlier slots. This provides a full 24-hour CPCB window at `t−168h`.
2. Require aware timestamps and convert to Asia/Yangon. Sort, reject duplicates/off-grid times, and reindex to hourly frequency. Missing/negative/nonfinite pollutant values become missing; no interpolation, forward fill, backward fill, zeros or US AQI substitution.
3. Map database fields to training names: `pm2_5→pm25`, `pm10→pm10`, `carbon_monoxide→co_ug_m3`, `nitrogen_dioxide→no2_ug_m3`, `sulphur_dioxide→so2_ug_m3`, `ozone→o3_ug_m3`. All raw inputs are µg/m³. Model `co = co_ug_m3 / 1000`; other features use µg/m³.
4. Recompute each hourly CPCB AQI from real raw history using the dashboard's copied `cpcb.py`. Use its 24-hour/8-hour means, completeness requirements, half-up rounding, maximum subindex, and open-ended Severe safeguards. Never use source `aqi`/`us_aqi`. Verify the latest stored CPCB result agrees when it is present; reject an incompatible stored version.
5. Generate features in the exact saved order:
   - AQI and six pollutant lags: 1, 2, 3, 6, 12, 24, 48, 72, 168 hours (63 features).
   - AQI rolling mean/max/min/sample std for 3, 6, 12, 24 hours (16).
   - Six pollutant rolling mean/sample std for the same windows (48). Windows include origin `t`; `min_periods=window`, std `ddof=1`.
   - Pollutant and AQI changes: `value(t)−value(t−lag)` for 1, 3, 6, 12, 24 hours (35).
   - Pollutant and AQI trends: `(value(t)−value(t−w))/w` for 3, 6, 12 hours (21).
   - Pollutant and AQI acceleration: `diff(1)−diff(3)/3` (7).
   - `pm25_pm10_ratio = pm25 / pm10`, with zero PM10 producing missing; `pm25_dominance = pm25 / (pm25+pm10+1e−6)` (2).
   - Sine/cosine of Yangon hour/24, day-of-week/7 (Monday=0), day-of-year/365.25 (January 1=1) (6).
6. Reject missing/nonfinite latest features and unavailable numeric current CPCB AQI. Convert the ordered feature row to float32 exactly as training did. Mark observations older than three hours as stale. Complete delayed history can produce an explicitly stale forecast at its actual old origin on cold start; later requests preserve the generated time. A new unusable origin may retain a previously successful forecast with a warning and separate latest-observation metadata. Never silently choose an earlier convenient origin or present it as current.
7. Run **all 24 pretrained regressors** on the same origin row. `raw_predicted_cpcb_aqi = current_cpcb_aqi + predicted_delta`. Return this sum and its delta. The displayed `predicted_cpcb_aqi` is clipped to 0–500, matching the original training evaluation; expose `clipped` explicitly.

Regression fixtures are genuine public dashboard observations fetched on 2026-10-10. The expected feature vector was generated by independently executing the original training functions, without calling training. It matches the inference vector exactly after float32 conversion. Fixtures are for tests only and are never a production data fallback.

CAMS modeled data are not instrument measurements or official CPCB station reports. Saved metrics are training metadata; this implementation does not establish new out-of-sample forecast accuracy or confidence intervals. Joblib artifacts are trusted local user files; never replace them with untrusted pickle downloads. XGBoost 3.2.0 issued one older-serialization warning; all 24 models nevertheless passed real-input prediction checks in the pinned environment. Artifacts were not rewritten.

Forecast caching, outage behavior and exact automatic update configuration are documented in `AUTOMATIC_UPDATES.md`.
